Getting started

From installer to first answer, in three steps.

1Install Rafeeq

Download the installer for your platform from the Download page. If you are not sure which variant to pick, the one with the starter model included is the easiest way to get going.

2Add a model (standard installer only)

If you installed the standard build, Rafeeq needs at least one .gguf model file before it can chat.

  1. aGo to huggingface.co and search for a model with GGUF in the name.
  2. bDownload a quantized file. One named like *.Q4_K_M.gguf is a good balance of size and quality.
  3. cOpen Rafeeq, go to the Models screen, and click Open models folder. Drop the file in, then click Refresh.
Models folder, standard installer on Windows
C:\Users\[you]\AppData\Local\com.ayoubedahlouli.rafeeq\models
The Models screen always shows the exact path for your install.

3Start chatting

Load a model from the Models screen, then pick a mode depending on what you are working on.

Set up local RAG

RAG mode needs a second, small embedding model, not your chat model. For example, nomic-embed-text-v1.5. Sideload it the same way as a chat model, then select it from RAG mode and index a folder of documents.

Verify it is really offline

Rafeeq makes zero network calls at runtime, by construction. You can test this yourself: block network access at the OS level (a firewall rule, a disabled adapter or an air-gapped VM) and Rafeeq will run identically. The app also shows an offline status indicator in the header.
