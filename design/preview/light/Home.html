What does Q4_K_M mean in a model file name?
It describes how the model's weights are compressed, called quantization. Q4 means roughly 4 bits per weight, and K_M is a mixed method that keeps more precision where it matters. It is a common balance between file size and quality.

No API keys. No cloud calls. No telemetry.

The model, the runtime and your data never leave the machine, verifiably and not just by policy.

01
Zero network calls

Rafeeq makes no network calls at runtime, by design and by construction. Block your network and it runs identically.

02
Runs entirely on-device

Powered by llama.cpp and quantized GGUF models on CPU. No GPU required, no API keys, no cloud.

03
Built for restricted machines

Corporate VMs, air-gapped networks, regulated industries. Rafeeq works where cloud AI tools cannot.
