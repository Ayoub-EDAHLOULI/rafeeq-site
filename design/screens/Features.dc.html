Features

Everything Rafeeq can do

All of it runs on-device. Nothing here needs, or uses, an internet connection.

Local chat

Prompt in, streamed response out, powered by a small quantized model running on CPU. No account, no rate limits, no usage sent anywhere.

Model manager

Point Rafeeq at a sideloaded .gguf file, swap models, and see size and quantization at a glance. Save named profiles for quick switching.

Code-help mode

Paste or select code, ask questions, get explanations or suggestions. Chat and explain only. Rafeeq never executes code.

Document Q&A and summaries

Load a local .txt, .md, .docx or .pdf file and ask about its contents, or get a summary. Long documents are truncated to fit the model's context.

Local RAG

Index a folder of documents with a sideloaded embedding model, then ask questions answered from the most relevant retrieved passages. All computed on-device.

Session history

Conversations are saved automatically and can be resumed from the sidebar, so nothing is lost between sessions.

Verifiably offline

An in-app indicator and a hand-maintained dependency allowlist confirm that no network-capable plugin is registered in the build. Block your network and Rafeeq runs identically.

Good to know

What Rafeeq does and doesn't do today, stated plainly.

Chat and explain only

Rafeeq never executes code, in code-help mode or anywhere else.

CPU only, no GPU needed

Small quantized GGUF models run on ordinary machines through llama.cpp.

You bring the model

The standard installer includes none. The other installer includes a small starter model, Qwen2.5-0.5B-Instruct.

Long documents are truncated

A document longer than the model's context is cut to fit.

Windows first

macOS and Linux builds are on the way.

See it run with the network off.

Install Rafeeq, block network access, and chat.
