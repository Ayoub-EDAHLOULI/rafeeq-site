Installing on a machine with no internet

Use the standard installer and bring the model over yourself.

  1. 1Download on a connected computerGet the standard installer, and a .gguf model file from Hugging Face. A file ending in Q4_K_M is a good balance of size and quality.
  2. 2Copy both files acrossUse a USB drive or an internal file share.
  3. 3Install, add the model, refreshOpen Rafeeq, go to Models, choose Open models folder, drop the file in, then click Refresh.
